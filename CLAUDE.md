# Yorozuya

Android player in Kotlin + Compose. See DECISIONS.md — tech stack, decisions, version breakdown.

## How to work with me

I'm learning Android development from scratch, with experience in C++/C#/Python. The goal of the project is to understand, not just get a finished app.

* Don't write code silently. First, explain what you are going to do and why.
* When suggesting changes, explain what each new construct does, especially if it's specific to Kotlin or Android.
* We co-work, share ideas, I try to write them myself, if I fail, then ask you for help.
* Talk in language I address you, but all comments in code should stay in English.
* Keep explanations concise and to the point.
